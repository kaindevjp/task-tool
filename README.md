# task-tool

コマンドラインで動作するシンプルなタスク管理ツールです。タスクの追加・一覧表示・完了・削除をCLIで行えます。データは `tasks.json` にローカル保存されます。

---

## 必要な環境

- Python 3.8 以上

外部ライブラリは不要です。標準ライブラリのみで動作します。

---

## インストール方法

```bash
git clone <リポジトリURL>
cd task-tool
```

インストール手順はこれだけです。追加のパッケージインストールは不要です。

---

## 使い方

### タスクを追加する

```bash
python task.py add "タスクのタイトル"
```

### タスク一覧を表示する

```bash
python task.py list
```

### タスクを完了にする

```bash
python task.py done <ID>
```

### タスクを削除する

```bash
python task.py delete <ID>
```

### ヘルプを表示する

```bash
python task.py --help
```

---

## 使用例

```bash
# タスクを追加
$ python task.py add "仕様書を読む"
タスクを追加しました: [1] 仕様書を読む

$ python task.py add "レビューコメントを返す"
タスクを追加しました: [2] レビューコメントを返す

# 一覧を表示
$ python task.py list
[1] 未完了 | 仕様書を読む | 作成: 2026-04-30 10:00:00
[2] 未完了 | レビューコメントを返す | 作成: 2026-04-30 10:01:00

# タスクを完了にする
$ python task.py done 1
タスクを完了にしました: [1] 仕様書を読む

# タスクを削除する
$ python task.py delete 2
タスクを削除しました: ID 2
```

---

## 機能一覧

| 機能 | コマンド | 説明 |
|------|----------|------|
| タスク追加 | `add <タイトル>` | 新しいタスクを追加する。IDは自動採番。 |
| 一覧表示 | `list` | 全タスクをID・状態・タイトル・作成日時で表示する。 |
| タスク完了 | `done <ID>` | 指定IDのタスクを完了状態にする。 |
| タスク削除 | `delete <ID>` | 指定IDのタスクを削除する。 |

---

## データ形式

タスクは `tasks.json` にJSON形式で保存されます。

```json
[
  {
    "id": 1,
    "title": "仕様書を読む",
    "done": false,
    "created_at": "2026-04-30 10:00:00"
  }
]
```
